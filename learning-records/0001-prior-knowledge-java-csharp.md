# 先验知识：精通 Java 与 C#，目标全栈

用户自称"proficient in Java and C#"，通过问答确认了以下背景：目标为全栈开发（前端框架 + Node.js 后端统一 TS）；教学方式偏好概念对照（C#/Java → TypeScript）；每课 15-20 分钟；已有 Node.js v24 + 编辑器环境（tsc 未全局安装）。

**Implications**: 不需要教授 OOP 基础概念（类、接口、泛型、继承、枚举、访问修饰符均已掌握），只需教授 TS 语法差异与 JS 运行时特性。课程核心价值应放在 TS 独有的内容：类型擦除心智模型、结构类型、联合类型/类型收窄、以及 JS 生态工具链（npm/tsconfig/构建）。可假设用户能快速看懂语法相近的代码。后续每课应明确标注"这是新的"vs"这是你已经知道的"。
