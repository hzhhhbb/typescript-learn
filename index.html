TypeScript 全栈课程

从 C#/Java 到 TypeScript 全栈

15 课完整学习路线：语言核心（类型系统 → 工程实践 → 类型编程）→ 生态四层（npm → Node → Vite → React）。每课 15-20 分钟，概念对照 C#/Java，含可运行练习与测验。

📌 教学使命 · 📚 学习资源 · 📝 教学笔记

阶段一：语言核心（0001-0011）

  • Lesson 0001让 TypeScript 跑起来
    环境搭建、类型擦除心智模型、编译管线
  • Lesson 0002结构类型
    TS 与 C#/Java 最根本的类型系统差异
  • Lesson 0003联合类型与类型收窄
    string | number、字面量联合、可辨识联合、穷尽性检查
  • Lesson 0004null、undefined 与严格空检查
    两个"空"、可选链、空值合并、非空断言
  • Lesson 0005泛型
    运行时擦除、extends 约束、infer 预告
  • Lesson 0006函数与对象类型
    函数类型、回调、重载、readonly、索引签名
  • Lesson 0007类与继承的 TS 细节
    参数属性、两种 private、abstract、装饰器
  • Lesson 0008异步与 Promise
    async/await、fetch 错误模型、Promise.all
  • Lesson 0009模块系统与工程配置
    import/export、CJS vs ESM、tsconfig 深入、npm scripts
  • Lesson 0010类型安全实战项目
    从零搭 Todo API：类型先行、运行时校验、事件驱动
  • Lesson 0011进阶类型（类型编程）
    keyof、映射类型、条件类型、infer——含逐步推导

阶段二：生态四层（0012-0015）

  • Lesson 0012npm 与 npx
    工具层：装包、语义化版本、npx 跑命令
  • Lesson 0013Node.js 运行时
    运行时层：事件循环、内置模块、Node vs 浏览器
  • Lesson 0014Vite 构建工具
    构建层：dev server、HMR、打包、tsc 分工
  • Lesson 0015React 全景
    框架层：UI = f(state)、组件、useState/useEffect、全栈闭环

阶段三：差异化进阶（0016-0019）

  • Lesson 0016Node 并发模型
    worker_threads（独立 V8 + 消息传递）、cluster、Streams 与背压
  • Lesson 0017NestJS 后端框架
    ASP.NET 的 TS 版：装饰器 DI、管道校验、tsx 的坑
  • Lesson 0018Prisma + Zod 数据层
    schema-first 类型安全 ORM + 校验与类型合一
  • Lesson 0019tRPC 端到端类型安全
    类型即契约：调后端函数像调本地函数，改签名前端编译期报错
